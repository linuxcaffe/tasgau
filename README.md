# Tasgau

**tasgau - (n.) tasks**

A simple web interface to [TaskWarrior](https://taskwarrior.org/).

The goal is to provide just enough of a wrapper around the cli that the tool becomes convenient to use from any device with a web browser.

I'm making this for me and not intending to maintain this as a general solution - but the code is here so feel free to fork it if you find it useful.
